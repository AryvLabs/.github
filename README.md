# .github

This repository holds organisation-wide configuration for [Aryv Labs](https://aryvlabs.com/).

## Contents

| Path | Purpose |
|---|---|
| `profile/README.md` | The profile displayed on the Aryv Labs organisation page |
| `standards/CODING_STANDARDS.md` | Organisation-wide coding standards for all repositories |

## Notes

- Community health files added to this repository (for example, contributing guidelines or a security policy) serve as defaults for repositories in the organisation that do not provide their own.
- This README describes the repository only. The organisation profile is in `profile/README.md`.
